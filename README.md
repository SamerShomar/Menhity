## الميزات

### للزائر
- صفحة رئيسية تعرض الإحصائيات الحيّة والمنح المميّزة.
- **اكتشف المنح**: بحث نصّي + فلاتر متعددة (الدولة، مستوى الدراسة، التخصص، نوع التمويل،
  متطلبات اللغة) + ترتيب + ترقيم صفحات — كل ذلك عبر الرابط فيعمل بدون جافاسكربت وقابل للمشاركة.
- صفحة تفاصيل المنحة: نبذة، شروط الأهلية، التخصصات، المستندات المطلوبة، المزايا،
  مع سايدبار ثابت يعرض عدّاد الموعد النهائي وفهرس المحتويات.
- صفحات: من نحن، الأسئلة الشائعة، مركز المساعدة، تواصل معنا، الشروط، الخصوصية.

### للطالب
- **مصادقة كاملة**: تسجيل، دخول، استعادة كلمة المرور برمز تحقق من 6 أرقام، إنشاء كلمة مرور جديدة.
- **الملف الأكاديمي**: معلومات شخصية، مؤهلات، خبرات، مهارات، لغات، شهادات، مشاريع، اهتمامات —
  مع حساب تلقائي لنسبة الاكتمال.
- **مطابقة ذكية**: خوارزمية تحسب نسبة توافق كل منحة مع الملف، وتعرض **أسباب التوافق**
  تحت «لماذا تناسبني؟».
- **المحفوظات** مع عدّاد تنازلي لكل موعد، ويتغيّر شكل زر البطاقة حسب قرب الموعد.
- **المستندات**: رفع بالسحب والإفلات مع تصنيف نوع المستند.
- **الإشعارات**: مصنّفة بالنوع ومجمّعة زمنياً، مع تحديد الكل كمقروء.
- **الإعدادات**: تغيير كلمة المرور، الخصوصية، **الجلسات والأجهزة النشطة**،
  تنبيهات البريد، اللغة والمنطقة الزمنية، ومنطقة الخطر (تعطيل/حذف الحساب).

### أدوات الذكاء الاصطناعي
خمس أدوات تقرأ الملف الأكاديمي تلقائياً كسياق:

| الأداة | الوظيفة |
|---|---|
| إنشاء السيرة الذاتية | ويزرد من 5 خطوات ينتهي بإحالة الطلب إلى خبير أكاديمي |
| تحسين السيرة الذاتية | تحليل نص السيرة واقتراح تحسينات |
| إنشاء خطاب الدافع | توليد خطاب مخصّص للمنحة المستهدفة |
| تحسين خطاب الدافع | مراجعة الخطاب وتحسين محتواه وأسلوبه |
| تقييم الملف الشخصي | تقييم الجاهزية وتحديد الفجوات وخطة عمل |

**خدمة صياغة السيرة الذاتية** مجانية وتمرّ بمسار كامل: إرسال الطلب ← إسناد تلقائي لخبير ←
تايملاين بأربع مراحل ← تقرير توافق ATS ← تسليم. مع إمكانية مراسلة الخبير.

### لوحة التحكم الإدارية
`/admin` — محمية بالأدوار (مدير النظام / مشرف):

- **الرئيسية**: إحصائيات + لوحة «تحتاج إلى انتباه» + إجراءات سريعة.
- **إدارة المنح**: جدول بفلاتر وبحث، إنشاء/تعديل/نشر/أرشفة/حذف.
- **المستخدمون**: جدول، تغيير الأدوار، إيقاف الحساب بسبب، تصدير CSV.
- **أدوات الذكاء الاصطناعي**: تفعيل/تعطيل كل أداة + سجل آخر التشغيلات ونسبة النجاح.
- **الطلبات**: متابعة طلبات صياغة السيرة الذاتية وتحريك مراحلها.
- **الإشعارات**: إرسال إشعار جماعي للطلاب.
- **التقارير والإحصائيات**: رسوم بيانية (منح حسب الدولة، التخصصات، توزيع الحالات،
  منحنيات الاستخدام والتسجيلات) مع عرض جدولي بديل لكل رسم.
- **الإعدادات**: حالة التكاملات وحجم البيانات وسجل الإجراءات الإدارية.

## التقنيات

| الطبقة | التقنية |
|---|---|
| الإطار | Next.js 15 (App Router) + React 19 |
| اللغة | TypeScript |
| التنسيق | Tailwind CSS v4 (RTL كامل) |
| قاعدة البيانات | PostgreSQL 16 |

الخطوط: **Tajawal** للنصوص و**Cairo** للعناوين، عبر `next/font`.

## التشغيل محلياً

### المتطلبات
- Node.js 20 أو أحدث
- PostgreSQL 16 يعمل محلياً

### الخطوات

```bash
# 1) تثبيت الحزم
npm install

# 2) إعداد متغيرات البيئة
cp .env.example .env
# ثم عدّل DATABASE_URL و AUTH_SECRET في ملف .env

# 3) إنشاء قاعدة البيانات (مرة واحدة)
createdb menhity
createdb menhity_shadow

# 4) تطبيق الترحيلات
npx prisma migrate dev

# 5) تعبئة بيانات تجريبية
npm run db:seed

# 6) التشغيل
npm run dev
```

ثم افتح <http://localhost:3000>

## قاعدة البيانات

السكيما تضم **32 نموذجاً** مقسّمة إلى:

- **المستخدمون والمصادقة**: `User`, `Session`, `VerificationCode`
- **الملف الأكاديمي**: `StudentProfile`, `Education`, `Experience`, `ProfileSkill`,
  `ProfileLanguage`, `Certification`, `Project`, `Interest`
- **المنح**: `Scholarship` + جداول فرعية للمستويات والتخصصات وشروط الأهلية
  والمستندات المطلوبة والمزايا
- **علاقة المستخدم بالمنح**: `SavedScholarship`, `ScholarshipMatch`, `Application`
- **المستندات والإشعارات**: `Document`, `Notification`
- **خدمة السيرة الذاتية**: `ExpertProfile`, `CvOrder`, `CvOrderEvent`, `CvOrderNote`, `CvAtsCheck`
- **الذكاء الاصطناعي والإدارة**: `AiTool`, `AiToolRun`, `AuditLog`, `ContactMessage`

### ملاحظة على المعدل التراكمي
تُخزَّن المعدلات كقيمة + نظام (`gpaValue` + `gpaScale`) لدعم أنظمة 4.0 و5.0 والنسبة المئوية
معاً، وتُحوَّل إلى نسبة مئوية موحّدة عند المقارنة في خوارزمية المطابقة.

## متغيرات البيئة

| المتغيّر | إلزامي | الوصف |
|---|:---:|---|
| `DATABASE_URL` | ✅ | رابط الاتصال بـ PostgreSQL |
| `SHADOW_DATABASE_URL` | للتطوير | قاعدة الظل التي يستخدمها Prisma Migrate |
| `AUTH_SECRET` | ✅ | مفتاح توقيع الجلسات (32 حرفاً على الأقل) |
| `ANTHROPIC_API_KEY` | ❌ | بدونه تعمل أدوات الذكاء الاصطناعي بوضع المحاكاة |
| `NEXT_PUBLIC_APP_URL` | ❌ | عنوان التطبيق العام |

> **مهم للإنتاج:** غيّر `AUTH_SECRET` إلى قيمة عشوائية طويلة —
> `openssl rand -base64 48`

## ملاحظات تشغيلية

### ما يعمل فعلياً
كل شيء موصوف أعلاه يعمل مقابل قاعدة بيانات حقيقية — لا توجد بيانات وهمية مثبّتة في الواجهات.

### ما يحتاج ربطاً خارجياً قبل الإنتاج

| الميزة | الحالة | المطلوب |
|---|---|---|
| إرسال البريد الإلكتروني | رموز التحقق تُطبع في سجل الخادم أثناء التطوير | ربط مزوّد بريد (Resend / SendGrid / SES) |
| تسجيل الدخول بـ Google / Apple | الأزرار موجودة وتعرض رسالة توضيحية | إضافة بيانات اعتماد OAuth |
| توليد الذكاء الاصطناعي | يعمل بوضع المحاكاة | إضافة `ANTHROPIC_API_KEY` |
| إشعارات الواتساب | غير مفعّلة | ربط مزوّد رسائل |
| تخزين الملفات | يُحفظ محلياً في `public/uploads` | نقله إلى تخزين سحابي (S3 / R2) عند النشر |
| أرشفة المنح المنتهية آلياً | الحالة تُحدَّث يدوياً من لوحة الإدارة | إضافة مهمة مجدولة (cron) |

### الأمان
- كلمات المرور مشفّرة بـ bcrypt (12 جولة).
- الجلسات مخزّنة في قاعدة البيانات مع إمكانية إبطال أي جلسة فورياً.
- تغيير كلمة المرور يُنهي الجلسات على الأجهزة الأخرى.
- إيقاف الحساب من لوحة الإدارة يُنهي جميع جلساته.
- أسماء الملفات المرفوعة تُستبدل بمعرّفات عشوائية لمنع تجاوز المسار.
- كل أكشن يتحقق من ملكية العنصر قبل التعديل أو الحذف.
