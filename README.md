## الميزات

### للزائر
- صفحة رئيسية تعرض الإحصائيات الحيّة والمنح المميّزة وأدوات الذكاء الاصطناعي.
- **اكتشف المنح**: بحث نصّي + فلاتر متعددة (الدولة، المرحلة الدراسية، التخصص، نوع التمويل،
  شهادة اللغة) + ترتيب + ترقيم صفحات — كل ذلك محفوظ في الرابط فيكون قابلاً للمشاركة والرجوع.
- صفحة تفاصيل المنحة: نبذة، مزايا، شروط الأهلية، التخصصات، المستندات المطلوبة،
  مع بطاقة جانبية تعرض المعلومات السريعة وعدّاد الموعد النهائي.
- صفحات: من نحن، الأسئلة الشائعة، مركز المساعدة، تواصل معنا، الشروط، الخصوصية، و404.

### للطالب
- **مصادقة كاملة**: تسجيل، دخول، استعادة كلمة المرور برمز تحقق من ٦ أرقام، كلمة مرور جديدة.
- **الملف الأكاديمي**: معلومات شخصية، مؤهلات، خبرات، مهارات، لغات، شهادات، مشاريع، اهتمامات —
  مع حساب تلقائي لنسبة الاكتمال وتلميح لكل قسم ناقص.
- **مطابقة ذكية**: خوارزمية تحسب نسبة توافق كل منحة مع الملف وتعرض **أسباب التوافق**.
- **المحفوظات** مع عدّاد تنازلي لكل موعد.
- **المستندات**: رفع بالسحب والإفلات مع تصنيف نوع المستند وتحقّق من الصيغة والحجم.
- **الإشعارات**: مصنّفة بتابات (الكل، منح مطابقة، مواعيد التقديم) مع تحديد الكل كمقروء.
- **الإعدادات**: كلمة المرور، الخصوصية، التنبيهات، اللغة والمنطقة الزمنية،
  **الجلسات والأجهزة النشطة**، وإجراءات الحساب (تعطيل / حذف).

### أدوات الذكاء الاصطناعي
خمس أدوات تقرأ الملف الأكاديمي تلقائياً كسياق:

| الأداة | الوظيفة |
|---|---|
| إنشاء السيرة الذاتية | ويزرد من ٥ خطوات ينتهي بإحالة الطلب إلى خبير أكاديمي |
| تحسين السيرة الذاتية | تحليل نص السيرة واقتراح تحسينات |
| إنشاء خطاب الدافع | توليد خطاب مخصّص للمنحة المستهدفة |
| تحسين خطاب الدافع | مراجعة الخطاب وتحسين محتواه وأسلوبه |
| تقييم الملف الشخصي | تقييم الجاهزية وتحديد الفجوات وخطة عمل |

**خدمة صياغة السيرة الذاتية** مجانية وتمرّ بمسار كامل: إرسال الطلب ← إسناد تلقائي لخبير ←
تايملاين بأربع مراحل ← تقرير توافق ATS ← تسليم، مع مراسلة الخبير من صفحة المتابعة.

### لوحة التحكم الإدارية
`/admin` — محمية بالأدوار (مدير النظام / مشرف)، وتُحمَّل عند الطلب فقط (code splitting):

- **الرئيسية**: إحصائيات + لوحة «تحتاج انتباهك» + إجراءات سريعة.
- **إدارة المنح**: جدول بفلاتر وبحث، إنشاء/تعديل/تغيير الحالة/حذف — بنموذج كامل يشمل
  المراحل والتخصصات وشروط الأهلية والمستندات والمزايا.
- **المستخدمون**: تغيير الأدوار، إيقاف الحساب بسبب مكتوب، تصدير CSV.
- **أدوات الذكاء الاصطناعي**: تفعيل/تعطيل كل أداة + سجل آخر التشغيلات ونسبة النجاح.
- **الطلبات**: متابعة طلبات صياغة السيرة الذاتية وتحريك مراحلها.
- **الإشعارات**: بث إشعار جماعي للطلاب (الكل أو النشطون فقط).
- **التقارير والإحصائيات**: رسوم SVG مبنية يدوياً — منحنيات زمنية، أشرطة أفقية، وحلقة توزيع —
  كلها بتسميات مباشرة فلا يعتمد القارئ على اللون وحده.
- **الإعدادات**: بيانات المنصة، حالة التكاملات، حجم البيانات، وسجل العمليات الإدارية.

## التشغيل محلياً

### المتطلبات
- PHP 8.4 مع الامتدادات `pdo_pgsql` و`mbstring` و`intl`
- Composer 2
- Node.js 20 أو أحدث
- PostgreSQL 16 يعمل محلياً

### 1) قاعدة البيانات

```bash
createuser menhity --pwprompt
createdb menhity --owner=menhity
```

### 2) الخادم (Laravel)

```bash
cd backend
cp .env.example .env
# عدّل DB_PASSWORD في ملف .env

composer install
php artisan key:generate
php artisan migrate --seed
php artisan storage:link     # ضروري لعرض المستندات المرفوعة

php artisan serve            # http://127.0.0.1:8000
```

> اختصاراً: `composer run setup` ينفّذ كل ما سبق دفعة واحدة.

### 3) الواجهة (React)

في طرفية ثانية:

```bash
cd frontend
npm install
npm run dev                  # http://127.0.0.1:5173
```

خادم Vite يمرّر `/api` و`/storage` إلى Laravel تلقائياً، فلا حاجة لضبط CORS
ولا لمتغيّر بيئة في الواجهة أثناء التطوير.

ثم افتح <http://127.0.0.1:5173>

## واجهة الـ API

كل المسارات تحت `/api/v1` وتُعيد JSON دائماً. المصادقة بـ Bearer token من Sanctum.

| المجموعة | أمثلة |
|---|---|
| عام | `GET /meta` · `GET /stats` · `GET /ai-tools` · `POST /contact` |
| المصادقة | `POST /auth/register` · `POST /auth/login` · `GET /auth/me` · `POST /auth/logout` |
| استعادة كلمة المرور | `POST /auth/forgot-password` · `/verify-code` · `/reset-password` |
| المنح (مصادقة اختيارية) | `GET /scholarships` · `/featured` · `/facets` · `/{slug}` |
| لوحة الطالب | `GET /dashboard` · `/profile` · `/documents` · `/notifications` · `/saved` |
| الإعدادات والجلسات | `PUT /settings/*` · `GET /sessions` · `DELETE /sessions/{id}` |
| أدوات الذكاء | `POST /ai-tools/{key}/run` |
| طلبات السيرة الذاتية | `GET /cv-orders/readiness` · `POST /cv-orders` · `GET /cv-orders/{id}` |
| لوحة الإدارة | `/admin/dashboard` · `/admin/scholarships` · `/admin/users` · `/admin/reports` … |

المصادقة الاختيارية على مسارات المنح تعني أن الزائر يرى المنح كاملة،
بينما يرى المستخدم المسجّل نسبة المطابقة وحالة الحفظ في النتيجة نفسها.

## قاعدة البيانات

**31 جدولاً للمجال** موزّعة على ثمانية ترحيلات (إضافةً إلى جداول Laravel الداخلية):

- **المستخدمون والمصادقة**: `users`, `personal_access_tokens`, `verification_codes`
- **الملف الأكاديمي**: `student_profiles`, `educations`, `experiences`, `profile_skills`,
  `profile_languages`, `certifications`, `projects`, `interests`
- **المنح**: `scholarships` + جداول فرعية للمراحل والتخصصات وشروط الأهلية
  والمستندات المطلوبة والمزايا
- **علاقة المستخدم بالمنح**: `saved_scholarships`, `scholarship_matches`, `applications`
- **المستندات والإشعارات**: `documents`, `notifications`
- **خدمة السيرة الذاتية**: `expert_profiles`, `cv_orders`, `cv_order_events`,
  `cv_order_notes`, `cv_ats_checks`
- **الذكاء الاصطناعي والإدارة**: `ai_tools`, `ai_tool_runs`, `audit_logs`, `contact_messages`

### ملاحظة على المعدل التراكمي
تُخزَّن المعدلات كقيمة + مقياس (`gpa_value` + `gpa_scale`) لدعم أنظمة 4.0 و5.0 والنسبة المئوية
معاً، وتُحوَّل إلى نسبة مئوية موحّدة عند المقارنة في خوارزمية المطابقة.

### أوزان المطابقة
المرحلة الدراسية 30٪ · التخصص 25٪ · المعدل 20٪ · اللغة 15٪ · نوع التمويل 10٪.

## متغيرات البيئة

### الخادم — `backend/.env`

| المتغيّر | إلزامي | الوصف |
|---|:---:|---|
| `APP_KEY` | ✅ | يُولَّد بـ `php artisan key:generate` |
| `APP_URL` | ✅ | عنوان الخادم — يُبنى منه رابط المستندات |
| `DB_CONNECTION` | ✅ | `pgsql` |
| `DB_DATABASE` / `DB_USERNAME` / `DB_PASSWORD` | ✅ | بيانات الاتصال بقاعدة البيانات |
| `CLOUDFLARE_ACCOUNT_ID` + `CLOUDFLARE_API_TOKEN` | ❌ | Cloudflare Workers AI — حصة يومية مجانية بلا بطاقة دفع (يلزم المتغيّران معاً) |
| `CLOUDFLARE_MODEL` | ❌ | اسم نموذج Workers AI؛ الافتراضي `@cf/meta/llama-3.3-70b-instruct-fp8-fast` |
| `GEMINI_API_KEY` | ❌ | مفتاح Google Gemini — طبقة مجانية بحدود يومية |
| `ANTHROPIC_API_KEY` | ❌ | مفتاح Anthropic — بالاستهلاك المدفوع |
| `AI_PROVIDER` | ❌ | `cloudflare` أو `gemini` أو `anthropic`؛ بدونه يُختار أول مزوّد مضبوطة بياناته |

بدون أي مفتاح تعمل أدوات الذكاء الاصطناعي بوضع المحاكاة، فيبقى المشروع قابلاً للتشغيل
والعرض فور استنساخه.

### الواجهة
لا تحتاج متغيّرات بيئة أثناء التطوير — يمرّر Vite الطلبات إلى Laravel.
عند النشر على نطاق مختلف، اضبط `base` في `vite.config.js` أو أضف `VITE_API_URL`
واستخدمه في `src/api/client.js`.

## ملاحظات تشغيلية

### ما يعمل فعلياً
كل ما هو موصوف أعلاه يعمل مقابل قاعدة بيانات حقيقية — لا توجد بيانات وهمية مثبّتة في الواجهات.

### ما يحتاج ربطاً خارجياً قبل الإنتاج

| الميزة | الحالة | المطلوب |
|---|---|---|
| إرسال البريد الإلكتروني | رموز التحقق تُطبع في سجل الخادم أثناء التطوير | ربط مزوّد بريد (Resend / SES / SMTP) |
| تسجيل الدخول بـ Google / Apple | الأزرار موجودة وتعرض رسالة توضيحية | إضافة بيانات اعتماد OAuth |
| توليد الذكاء الاصطناعي | يعمل بوضع المحاكاة | إضافة `CLOUDFLARE_ACCOUNT_ID` + `CLOUDFLARE_API_TOKEN` أو `GEMINI_API_KEY` (كلاهما مجاني) أو `ANTHROPIC_API_KEY` |
| تخزين الملفات | قرص `public` المحلي | نقله إلى تخزين سحابي (S3 / R2) عند النشر |
| أرشفة المنح المنتهية آلياً | الحالة تُحدَّث يدوياً من لوحة الإدارة | إضافة مهمة مجدولة (scheduler) |

### الأمان
- كلمات المرور مشفّرة بـ bcrypt (12 جولة).
- كل توكن Sanctum يمثّل جهازاً، ويمكن إبطاله فرادى أو دفعة واحدة من صفحة الإعدادات.
- تغيير كلمة المرور يُنهي الجلسات على الأجهزة الأخرى، واستعادتها تُنهيها جميعاً.
- إيقاف الحساب من لوحة الإدارة يمنع الدخول عبر وسيط `active`.
- المستندات المرفوعة تُخزَّن بأسماء عشوائية، ويُتحقَّق من الصيغة والحجم قبل القبول.
- كل متحكّم يتحقّق من ملكية العنصر قبل التعديل أو الحذف.
- مسارات الإدارة محمية بوسيط `role:admin,moderator`، والحذف وتغيير الأدوار للمدير فقط.
